
# GaiAnQi Global Trading
## Global Trade Data Analysis — Version 1 Archive

### Overview

This directory preserves the original version of the
Global Trade Data Analysis portfolio project.

Version 1 established the initial foundation for
synthetic import transaction analysis, tariff exposure
assessment, compliance screening, and dashboard
development.

The project subsequently evolved into Version 2,
which introduces interconnected purchasing, supplier,
product, shipment, customs entry, and compliance
exception datasets.

### Original Project Scope

Version 1 included:

- Synthetic import transaction generation
- Import data analysis
- Tariff exposure analysis
- Preliminary compliance screening
- Trade analytics dashboards
- Supporting reports and datasets

### Original Baseline

- 500 synthetic import transactions
- Approximately $74.1 million in entered value
- 327 transactions flagged for preliminary review

These figures describe the original project baseline,
not current production import activity.

### Archive Organization

- `scripts/` — Original Python analysis and generation scripts
- `data/` — Historical datasets (to be archived)
- `dashboards/` — Original dashboard assets (to be archived)
- `outputs/` — Historical reports and generated outputs (to be reviewed)

All company information, transactions, and compliance
scenarios are fictional or synthetic.
